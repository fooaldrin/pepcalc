  • Calibrated SVG Barrel Readout: Real-time plunger meniscus alignment across 0.3 mL (30u), 0.5 mL (50u), and 1.0 mL (100u) U-100 barrels, as well as 1.0 mL (40u) U-40 graduated syringes, with automated sub-division resolution diagnostics.
